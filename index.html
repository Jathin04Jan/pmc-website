DWG 02 · STATE MACHINE · REV A
The State Machine

Twelve stages. No skipping. No silent edits.

Each stage must be completed and frozen before the next begins. Frozen stages become read-only forever — changes require a new version, and every transition demands a comment and an audit entry.

01
YetToStart
Conceptualized — the pipeline of upcoming projects.
02
Created
Project record born with code, budget, dates, and risk factor.
03
Started
Official kickoff. Team assigned, governance begins.
04

05
